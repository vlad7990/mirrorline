## Brand & Style

The design system embodies the archetype of a **calm, expert studio partner**. Designed specifically for high-calibre coaches, consultants, and independent practitioners, the system strips away the noise, hyperbole, and synthetic sheen typical of generative AI tools. 

Instead of glowing gradients, floating sparkles, or hyperbolic promises ("10x your growth"), the aesthetic is grounded, quiet, and deeply editorial. The user's creative video assets remain the visual heroes of every view. The UI acts as a bespoke, tactile workshop: structured around warm off-white canvas surfaces, crisp bordered cards, precise tabular data, and purposeful micro-copy that speaks with transparency and restraint.

Key emotional targets:
- **Quiet Authority:** Generous negative space, restrained color accents, and intentional typographic hierarchy instill immediate confidence.
- **Radical Transparency:** AI operations, agent tasks, and compliance metrics are surfaced cleanly as first-class UI citizens, replacing black-box automation with inspectable clarity.
- **Editorial Polish:** Refined high-density proportions, muted stone borders, and dark ink statement panels evoke a luxury publication workspace rather than generic enterprise SaaS.

## Colors

The palette establishes an intentional balance between an archival paper ground, stark typography, and surgical coral accents:

- **Primary (`#C8401C`):** Deep terracotta coral reserved for high-priority interactive triggers, primary commit actions, and critical buttons. Ensures high contrast (exceeding WCAG 4.5:1 against white).
- **Secondary / Accent (`#FF5A36`):** Vibrant vermilion coral dedicated exclusively to data indicators, linear sparklines, dynamic progress gauges, and system loop motifs. It is never used behind small white body text.
- **Accent Soft (`#FFE8E1`):** Gentle tinted ground for active navigational nodes, highlighted interactive states, and active agent execution indicators.
- **Canvas & Surface:** `#FAFAF7` provides a warm gallery-grade background that prevents screen glare; `#FFFFFF` cards provide elevated structure framed by crisp 1px borders (`#E6E4DD`).
- **Typography & Dark Panels (`#14171C`):** Deep charcoal ink serves as primary reading text and background fill for specialized "Learning Loop" studio insight modules.
- **Status Semantics:** Semantic indicators are soft-tinted backgrounds paired with darker foregrounds:
  - Passed / Published: `#E3F4EC` / `#145C40` (Dot: `#1F9D6B`)
  - Review Required: `#FBF0D9` / `#6E4A07` (Dot: `#C98A12`)
  - Blocked / Action Required: `#FBE3E3` / `#8E2626` (Dot: `#D23F3F`)
  - Scheduled / Info: `#E3ECFB` / `#1F4FA8` (Dot: `#2F6FDE`)
- **Dark Mobile Approvals Theme:** For rapid on-the-go review, dark mode shifts the canvas to `#0E1116` with `#161A21` surfaces, `#2A2F38` borders, and high-legibility `#FF7A5C` primary triggers.

## Typography

The typographical hierarchy is driven by two cuts of the Inter family: tightened geometric tracking for headings and display titles, and systematic standard tracking with tabular numeric support for dense UI grids.

- **Headlines & Titles:** Set with dense proportional kerning and negative tracking (`-0.01em` to `-0.02em`) to mirror luxury editorial layout and tight print broadsheets.
- **Metrics & Tabular Alignment:** The `metric-display` level enforces tabular numerals (`font-variant-numeric: tabular-nums`) to ensure vertical visual alignment across multi-column dashboard comparisons.
- **Eyebrows & Metadata:** Section markers above titles use uppercase letter-spaced metadata (`0.06em`), while body text enforces relaxed readability (`1.55` relative line-height) and strict sentence case across all labels, chips, and toasts.

## Layout & Spacing

The layout system is built upon a rhythmic 8px scale optimized for wide workspace ergonomics and vertical 9:16 mobile review streams.

### Layout Architecture
- **Desktop (1440px+):** Fixed 240px navigational sidebar anchored to the left. The remaining viewport fluidly expands with an outer section margin of 36px (`2.25rem`) and 20px–24px component gutters.
- **Main Workspace Composition:**
  - Header band with eyebrow context, dynamic greeting, secondary status summary, and pinned right-aligned primary trigger.
  - Multi-column metric row: 4 auto-equal columns.
  - Asymmetric split view: 2/3 primary operational stream ("Needs You" queue and daily feed) alongside a 1/3 ancillary activity and machine-learning intelligence column.
- **Mobile Approvals (390px Viewport):**
  - Single fluid column with 18px lateral margins.
  - Pinned thumb-accessible 56px bottom interaction bar.
  - Wide tabular data (such as content release matrices) cleanly scrolls with sub-container horizontal overflow rather than triggering canvas reflow.

## Elevation & Depth

Visual hierarchy is driven entirely through architectural borders and tone shifts rather than drop shadows.

- **Flat Border Construction:** Containers exist on the `#FAFAF7` background as flat `#FFFFFF` shapes defined by a crisp 1px `#E6E4DD` solid border. 
- **Active / Selection Rings:** Selected cards or focused items swap the neutral border for a high-contrast 2px `#14171C` solid contour without adding elevation offsets.
- **Ink Panels for Deep Cognitive Hierarchy:** Specialized insight containers (e.g., the "Learning Loop" module) invert the palette using solid `#14171C` surfaces with `#F2F2EE` text, instantly drawing focus as the most authoritative module on the board.
- **Minimalist Segmented States:** Active toggles within segment controls employ a nominal single-pixel ambient diffusion (`0 1px 2px rgba(20, 23, 28, 0.06)`) to convey mechanical travel without muddying the interface.
- **No Volumetric Artifacts:** The design strictly avoids multi-stop colored gradients, heavy drop shadows, outer glows, and glassmorphic blurs.

## Shapes

The design uses a clean, architectural curvature standard:

- **Cards & Primary Modules:** 12px border radius (`0.75rem`) for workspace containers, metric blocks, and approval queue cards.
- **Inputs & Action Elements:** 10px border radius for buttons, text fields, and segmented control wells.
- **Video Canvas Nodes:** 8px border radius for 9:16 vertical content cards and inner preview viewports; 4px–6px for micro-stills.
- **Badges, Chips & Progress Fills:** 9999px full pill radius for metadata, agent activity indicators, and timeline progress bars.
- **Signature Mark:** Clean circular geometry defining an open-loop vector arrow in accent coral (`#FF5A36`), symbolizing recurring automated distribution.

## Components

### Buttons
- **Primary:** Background `#C8401C`, text `#FFFFFF`, height 48px, horizontal padding 20px, radius 10px. Label text 14px bold (`label-md`). Hover: darkens 5%. Focus: 2px `#14171C` outline offset by 2px.
- **Secondary:** Background `#FFFFFF`, text `#14171C`, border 1px solid `#D6D3CA`, height 44px, padding 16px, radius 10px. 
- **Tertiary:** Borderless, text `#C8401C`, hover underline, 0 padding, height auto.

### Video Cards (9:16 Aspect Ratio)
- Outer container: `#FFFFFF` card, 12px radius, 10px padding, 1px `#E6E4DD` border.
- Visual frame: Locked 9:16 aspect ratio with 8px radius corners. Includes burned-in caption overlay anchored at bottom (`overlay-caption`, `#FFFFFF` with `#F3E9DC` sand highlight bar behind keyword text). Top badges: duration chip left (`0:24`), cut reference right (`#03`).
- Card details: Format tag, dynamic engagement score pill, compliance badge, inline approval actions ("Review", "Approve").

### Status Chips
- Pill geometry (9999px radius), height 24px, padding 2px 10px.
- **Passed:** Background `#E3F4EC`, text `#145C40`, typography `caption`.
- **Needs Review:** Background `#FBF0D9`, text `#6E4A07`, typography `caption`.
- **Blocked:** Background `#FBE3E3`, text `#8E2626`, typography `caption`.
- **Scheduled:** Background `#E3ECFB`, text `#1F4FA8`, typography `caption`.
- **Published:** Background `#EFEDE7`, text `#3E444D`, typography `caption`.
- Strict standard: Status chips always contain a text label; color is never used in isolation.

### Agent Status Pills
- Structural indicator: 8px circular status dot aligned with 13px regular text.
- **Working:** `#FF5A36` pulsing dot + "Working"
- **Idle:** `#A3A9B4` dot + "Idle"
- **Waiting for you:** `#C98A12` dot + "Waiting for you"
- **Blocked:** `#D23F3F` dot + "Blocked"

### Metric Tiles
- Surface: `#FFFFFF`, 12px radius, 18px 20px internal padding, 1px `#E6E4DD` border.
- Layout: Top meta label in `#5F6672`, large tabular value in `metric-display` (`30px`), inline accent coral sparkline (`#FF5A36`, 2px vector path, height 18px), and bottom contextual delta tag (`+18% vs last week` in `#1F9D6B`).

### Compliance Badges & Panels
- Summary banner: 1px solid `#1F9D6B` border on `#FFFFFF` card, containing a "Passed" pill and a detailed checklist with verified checkmarks: "No original footage reused", "Similarity index: 12% (threshold: 30%)", "Commercial audio rights cleared".
- AI Disclosures: Discrete 20px floating pill badge (`#FFFFFF`, opacity 0.92, text `#14171C`, 11px bold) displaying "AI scene" pinned to thumbnails using generative synthetic footage.

### Dark Mode Mobile Approval View
- Canvas shifted to `#0E1116`, card containers to `#161A21` with `#2A2F38` borders.
- Action CTA: 56px height, rounded 16px, background `#FF7A5C`, text `#14171C`, typography `body-medium`. Provides thumb-friendly one-tap bulk approval.
